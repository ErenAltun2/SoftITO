## 🎯 Konu Başlıkları

1. **Ekrana yazı yazdırma:** `print()`
2. **Yorum satırları:** tek satır (`#`) ve çok satırlı (`""" """`) yorumlar
3. **Değişkenler:** tanımlama, değer atama ve güncelleme
4. **Veri tipleri:** `int`, `float`, `str`, `bool` ve `type()` ile kontrol
5. **Temel matematik işlemleri:** toplama, çıkarma, çarpma, bölme, mod (`%`), üs alma (`**`)
6. **Kullanıcıdan veri alma:** `input()`
7. **Karşılaştırma operatörleri:** `>`, `<`, `==`
8. **Mantıksal operatörler:** `and`, `or`, `not`
9. **`if / elif / else` ile koşullu ifadeler**
10. **String işlemleri:** birleştirme, `len()`, `.upper()`, `.lower()`
11. **Basit programlar:** kullanıcıdan alınan sayılarla çarpma/kare alma

## 💡 Örnek

```python
yas = 20
kayitli_mi = True
sonuc = (yas > 18 and kayitli_mi)
print(sonuc)  # True
```
